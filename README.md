# Email Template Studio

Static React application for configuring fixed email templates, previewing them, and exporting compatible table-based HTML with inline CSS.

## Development

Use Node.js 22 and install dependencies with `npm ci`.

```bash
npm run dev
```

Quality gates:

```bash
npm run lint
npm run typecheck
npm run test:run
npm run build
```

The product architecture and implementation stages are defined in [ARCHITECTURE.md](./ARCHITECTURE.md).
