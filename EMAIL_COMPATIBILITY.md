# Совместимость email-шаблонов

## Статус проверки

Локальная статическая проверка выполнена для детерминированных default HTML
fixtures всех четырёх шаблонов. Проверены parseability, документные meta-теги,
табличная структура, inline-стили, Outlook VML, mobile media query и абсолютные
export-safe URL.

Ручной smoke test в Gmail, Outlook и Apple Mail не выполнен: внешние почтовые
клиенты и тестовые аккаунты в текущем окружении недоступны. Поэтому статусы ниже
означают ожидаемую совместимость по разметке, а не подтверждение реальной
доставкой письма.

## Матрица

| Клиент | Статус | Ожидаемое поведение | Известные различия |
| --- | --- | --- | --- |
| Gmail Web | Статически совместимо, ручной smoke не выполнен | Табличный layout, inline-стили, CTA-ссылка и HTTPS-изображения | Gmail проксирует изображения; часть head CSS может быть очищена, но письмо остаётся читаемым за счёт inline-стилей |
| Outlook desktop (Windows) | Статически совместимо, ручной smoke не выполнен | Word renderer получает presentation tables, 96 DPI setting и VML fallback для CTA | Скругления и метрики шрифтов могут отличаться; VML-кнопка имеет расчётную фиксированную ширину |
| Outlook Web | Статически совместимо, ручной smoke не выполнен | Используется обычная HTML CTA-ссылка и табличная раскладка | Отступы и переносы могут незначительно отличаться от desktop Outlook |
| Apple Mail (macOS/iOS) | Статически совместимо, ручной smoke не выполнен | Полные inline-стили, responsive media query и защита от автоформатирования | Системные настройки увеличения текста и dark mode пользователя могут менять визуальное восприятие |

## Проверяемые гарантии

- Полный HTML-документ содержит doctype, charset, viewport и Apple Mail meta.
- Внешний фон и контент построены на `table role="presentation"`.
- Основные визуальные свойства размещены inline; в `<style>` остаются reset,
  client-specific правила и mobile media query.
- CTA содержит обычную HTTPS-ссылку и условный VML `v:roundrect` для Outlook.
- Экспорт не содержит `blob:`, `data:` или `javascript:` URL.
- Default fixtures совпадают с результатом текущих renderer-функций побайтно.

## Fixtures и воспроизведение

Fixtures находятся в `src/email/compatibility/fixtures/`.

```bash
npm run fixtures:email
npm run fixtures:email:check
```

Первая команда осознанно перегенерирует fixtures после review изменений
renderer/core. Вторая ничего не записывает и завершится ошибкой при расхождении.

## Остаточные риски

- Реальное отображение зависит от версии клиента, политики организации,
  sanitizer-а и настроек dark mode.
- Outlook desktop может иначе измерять нестандартно длинные или широкие
  пользовательские подписи CTA, поскольку VML использует расчётную ширину.
- Доступность удалённых изображений, их MIME-типы, размеры и CDN-заголовки
  статически не проверяются.
- Доставляемость, spam-фильтры, tracking protection и переписывание ссылок
  находятся вне scope этой проверки.
